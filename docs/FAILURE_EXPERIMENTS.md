# 故障与恢复

| 场景 | 行为与验证 |
|---|---|
| 完整日缺一个小时 | 真实 23 小时输入被门禁拒绝，下游不发布；补齐缺失小时后成功 |
| 损坏 JSON、缺必要字段、跨小时记录 | 合成异常进入 quarantine，默认零坏行门槛阻止发布 |
| 未知类型与重复事件 | 原文保留到审计分支；相同重复排除，冲突内容不任意选一条 |
| SCD2 同刻名称冲突 | 隔离冲突键并拒绝维度发布；迟到观察重建时间线 |
| 临时门禁失败 | Airflow 原生 retry 恢复，成功构建阶段不因门禁重试重算 |
| ODS 排序内存不足 | 两次真实失败未激活候选；相同 24 小时、4,743,665 行输入恢复后发布成功，前三日指针不变 |

最后一个案例中，较小行组和磁盘缓存等组合配置通过复测，但 writer 阈值 1 仍触发排序回退。执行计划缺少显式 Sort 不足以证明内部 writer 不排序，需要核对聚合 executor 日志。

[公开汇总](../evidence/public/portfolio.json)包含恢复状态与报告 SHA；完整失败日志和原始数据留在本地，不作为仓库下载内容。
