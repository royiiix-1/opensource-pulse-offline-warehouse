# 限制

- 单机 WSL、HDFS 副本 1、Derby HMS、SQLite/SequentialExecutor；无生产用户、HA、多租户或 SLA。
- 七个固定 UTC 日期不代表 GitHub 全历史；派生副本和重复运行不累加到数据规模。
- SCD2 描述样本内的名称观察，未实现任意窗口的全历史维度合并；owner 前缀不等于组织身份。
- 下一周未覆盖，留存为 IMMATURE/null；合成数据中的比例仅验证规则，不是实际人群指标。
- PR/Issue 指标为动作事件数量，commit 声明计数与可见数组长度不同，缺失不等于零。
- 日期范围参数可用并有单测；真实范围回填证据为单日范围，七日构建采用逐日 DAG 批次。
- 本地版本指针不构成 Hive/HDFS 跨系统事务；绕过指针读取候选表不享有受控发布保证。
- NO_OP 仍读取和校验文件。代码字节变化可能触发新版本，即使变化只有注释。
- ODS 内存故障已恢复，但 writer 阈值 1 仍会回退排序；不宣称免排序。
- 性能实验只有本机预热后三次重复，未清空系统缓存，不具备统计显著性或生产外推保证。
- HMS/Spark UI 在 WSL 内存在通配监听，未配置外部转发，不宜直接暴露公网。
- 完整部署尚未验证任意主机可用；轻量 CI 不替代集群验收。
- 凭证扫描采用签名规则，不是形式化的无密钥证明。仓库排除原始数据、完整日志及逐用户/owner 结果。
