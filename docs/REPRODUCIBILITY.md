# 复现与证据

仓库提供代码、固定依赖描述、测试和汇总证据，不附带原始归档或现成集群。完整部署绑定已验证的 WSL 环境，见 [运行手册](RUNBOOK.md)。

- **portable**：Linux/Python 3.11，标准库单测、语法、文档链接、候选范围扫描；GitHub Actions 使用同一命令。
- **full**：既有部署下逐文件校验七日发布版本、168 个 HDFS gzip 和多日模型；YARN 重新检查表、分区、SCD2、独立聚合和原始行血缘。不会自动下载或重建数据。

[本机验收摘要](../evidence/public/local-validation.json)记录 502 项实时检查及 YARN 应用。历史汇总 JSON 保留当时的验证范围，早期记录中的未完成项不代表当前状态。原报告 SHA 用于关联本地审计档案，不是第三方签名或远程 CI 证明。

部署脚本中的本地路径、专属端口和 UID 缓存位置需要在其他机器上审阅。当前没有“任意主机从零部署都已通过”的证据。CI 成功只证明轻量检查通过，不代表已重建 2,980 万条数据。
